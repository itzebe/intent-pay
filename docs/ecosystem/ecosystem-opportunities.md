## Payment-adjacent ecosystem (for context)

The App Hub lists payment and trading apps, including a **Payments** category
(e.g. AnomaPay) and DEX aggregators (1inch, KyberSwap, Matcha, Kuru, Clober,
Uniswap, PancakeSwap). Intent Pay is a distinct, outcome-first payment layer, not
another swap UI.

## How Intent Pay fits

- **Payment infrastructure**, not a trading UI: the user states the outcome and
  the system resolves routing. This is complementary to the DEX/aggregator
  category, not a competitor to it.
- **Non-custodial and honest**: mainnet-only, verified settlement, no fabricated
  quotes — a good fit for a payments-focused ecosystem story.
- **Agentic-payments adjacent**: the intent model is a natural fit for x402 / MPP
  machine payments, which Monad documents as first-class.
